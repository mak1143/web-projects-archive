
## ✅ **Project Title: Smart Daily Planner PWA**

---

## 1. 📱 **General Requirements**

* **Responsive UI**: Mobile-first but works well on desktop (like a web app).
* **PWA Capabilities**:

  * Works offline.
  * Add to home screen (manifest + service worker).
  * Syncs tasks locally (IndexedDB/LocalStorage) and optionally with cloud later (Firebase).
* **Dark Mode** support (based on the theme in your image).

---

## 2. 📅 **Date-Based Task Management**

* Detect **user’s current date/time** using JavaScript:

  ```js
  const today = new Date().toLocaleDateString();
  ```
* Display date at the top (e.g., **March 9, 2020**).
* Automatically group tasks under the current date.

---

## 3. 📝 **Task Features**

Each task must have:

* ✅ **Completion toggle**
* 🏷️ **Tagging system** (with icons):

  * Shopping 🛒
  * Finance 💼
  * Wedding 💍
  * Freelance 📄
  * Custom tags (user-defined)
* 📌 **State indicators**:

  * "Incomplete" (unchecked)
  * "Completed" (checked + strike-through)
* 🧮 **Task summary** (e.g., `5 incomplete, 5 completed`)

---

## 4. ➕ **Add Task Feature**

* **Floating Action Button (FAB)** with "+" icon.
* Clicking the "+" opens a **modal or drawer** with:

  * Task title input
  * Tag selector (dropdown with icons)
  * Optional date/time selector (default to today)
  * Save button

---

## 5. 📊 **Dynamic Task Count Updates**

* Track number of **incomplete vs completed tasks**.
* Update header stats dynamically whenever task state changes.

---

## 6. 🌐 **Tech Stack Recommendation**

* **Frontend**:

  * HTML + CSS (Tailwind or custom)
  * JavaScript (or React for better state handling)
* **PWA Tools**:

  * `manifest.json`
  * Service Worker (using Workbox or manual)
* **Storage**:

  * LocalStorage (for MVP)
  * IndexedDB (for larger data handling)
* **Optional Cloud Sync**:

  * Firebase Realtime Database or Firestore for account-based storage

---

## 7. 🧪 **Bonus Features (Optional for MVP)**

* 🔁 Drag & drop to reorder tasks
* 🔔 Notifications for scheduled tasks (PWA push)
* 🌎 Multilingual or time zone support

const CACHE_NAME = "todo-pwa-cache-v1";
const urlsToCache = [
  "/",
  "/index.html",
  "/styles.css",
  "/app.js",
  "/manifest.json",
  "/icons/icon-192.png",
  "/icons/icon-512.png"
];

self.addEventListener("install", (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(urlsToCache))
  );
});

self.addEventListener("fetch", (event) => {
  event.respondWith(
    caches.match(event.request).then((response) => response || fetch(event.request))
  );
});


if ("serviceWorker" in navigator) {
  window.addEventListener("load", () => {
    navigator.serviceWorker.register("/service-worker.js")
      .then((reg) => console.log("Service Worker Registered", reg.scope))
      .catch((err) => console.log("Service Worker Error", err));
  });
}
